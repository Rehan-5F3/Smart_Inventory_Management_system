# Smart Inventory Management System

A full-stack inventory management web application designed to help businesses manage products, stock, sales, and inventory information through a centralized dashboard.

## 🚀 Features

- 📊 Interactive dashboard for monitoring inventory and sales
- 📦 Product management and inventory tracking
- 🛒 Sales management
- 🔐 User authentication and protected routes
- 📈 Inventory and sales insights through charts
- ☁️ Cloudinary integration for image management
- 🗄️ Database integration for persistent data storage
- 💻 Responsive frontend interface

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js
- REST APIs

### Database & Services
- MongoDB
